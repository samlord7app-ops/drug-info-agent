# 📸 影像辨識藥品用法用量系統 (免 API Key 全本地智慧版)

一套 **完全不需 API Key、零費用、全本地運行** 的 **藥袋與處方箋智慧辨識系統**。結合瀏覽器端開源繁體中文 OCR (`Tesseract.js` `chi_tra+eng`) 與後端 **台灣臨床處方規則與藥品知識庫解析引擎**，自動將台灣醫療院所的「藥袋」與「門診/慢箋處方箋」照片轉換為結構化 JSON、白話服藥指引與一日用藥時間表（早・中・晚・睡前・需要時）。

---

## ✨ 核心功能（100% 免 API Key）

1. **🛡️ 免 API Key 全本地免費辨識**
   - 前端內建開源 `Tesseract.js` 繁體中文 + 英文 OCR 引擎，搭配後端 [`vision_engine.py`](file:///c:/Users/lw2wf/OneDrive/文件/自動排班/影像辨識藥品用法用量/vision_engine.py) 處方規則解析與台灣常見健保用藥知識庫，無須申請任何雲端金鑰即可離線/本地運作。
2. **📸 多元影像輸入與相機實拍**
   - 支援檔案上傳、滑鼠拖曳、剪貼簿 `Ctrl+V` 直接貼上截圖，以及手機/電腦鏡頭即時拍照。
   - 提供「藥袋 OCR 文字檢視與手動微調框」，可隨時貼上或修正文字並即時重新排程。
3. **🕒 智慧一日用藥時間表（早 / 中 / 晚 / 睡前 / PRN）**
   - 自動識別處方頻率代碼（如 `QD`, `BID`, `TID`, `QID`, `HS`, `PRN`, `AC`, `PC`, `PO`），將多筆藥品自動分發至對應時段卡片，清楚標示每次吃幾顆（包含「半顆 `0.5` 錠」提醒）與飯前/飯後。
4. **🔊 國語語音朗讀與衛教單列印**
   - 一鍵語音播報單一藥品或整張處方箋的白話吃法，方便長輩聆聽。
   - 支援一鍵列印 A4 衛教時間表、匯出 CSV 報表與複製結構化 JSON。
